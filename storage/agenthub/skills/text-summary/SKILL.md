# 文本摘要

## 适用场景

当用户希望总结、概括、提炼要点、压缩长文本时使用本技能。

## 执行方式

1. 读取用户提供的文本，识别主题、结论和关键事实。
2. 优先保留明确结论、数字、责任方、时间和风险。
3. 删除重复表达、寒暄和无关背景。
4. 输出简短摘要和关键要点。

## 输出要求

- 严格按以下格式输出：

```md
摘要：
用 1 段话概括核心背景、结论和后续安排。

关键要点：
- ...
- ...

待办：
- ...
- ...
```

- 如果原文没有待办事项，则省略“待办”部分。
- 不编造原文没有的信息。
- 原文信息不足时，明确说明缺少什么。

## 边界

本技能只做文本整理，不做事实核验，不替代专业审查。
