天气查询技能

两种免费服务，无需 API Key。

wttr.in（主要）

快速查询一行命令：

curl -s "wttr.in/Beijing?format=3"
# 输出: Beijing: ⛅️ +15°C

紧凑格式：

curl -s "wttr.in/Beijing?format=%l:+%c+%t+%h+%w"
# 输出: Beijing: ⛅️ +15°C 45% ↙12km/h

完整预报：

curl -s "wttr.in/Beijing?T"

格式代码：

%c 天气状况 · %t 温度 · %h 湿度 · %w 风速 · %l 位置 · %m 月相

提示：

  • URL 编码空格: wttr.in/New+York
  • 机场代码: wttr.in/PEK
  • 单位: ?m 公制 ?u 英制
  • 仅今天: ?1 · 仅当前: ?0
  • 导出 PNG: curl -s "wttr.in/Beijing.png" -o /tmp/weather.png

Open-Meteo（备用，JSON 格式）

免费、无需 Key，适合程序化调用：

curl -s "https://api.open-meteo.com/v1/forecast?latitude=39.9&longitude=116.4&current_weather=true"

先查询城市坐标，再请求天气数据。返回 JSON 包含温度、风速、天气代码。
